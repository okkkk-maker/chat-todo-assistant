# ⚡ 待办自动汇总助手 (Chat To-Do Assistant)

> **版本**：v1.5.4 · **适用系统**：Windows 10 / 11 64 位  
> **核心定位**：本地多平台聊天消息（QQ NT、个人微信 4.x、企微、飞书、钉钉）**安全只读增量采集** ➔ 智能提炼带溯源待办清单 ➔ 定时推送到企业微信。

> [!IMPORTANT]
> **使用前必读（引导与平台测试状态说明）**：
> 1. **必须先在「系统设置」中确认配置后才能使用**：程序首次启动默认处于安全待命状态（`WAITING_CONFIG`），不会自动采集。请务必先通过首次启动向导或进入控制台 **【⚙️ 系统设置】** 页面确认配置模式、勾选需要启用的平台、填写/校验凭证并点击 **「保存配置并应用」**，确认配置之后才能正常使用。
> 2. **钉钉和飞书通道尚未经过测试**：目前仅 **腾讯 QQ（NT 本地库）**、**个人微信（4.x 本地库）** 与 **企业微信推送** 经过完整实机验证；**飞书（Feishu）与钉钉（DingTalk）通道目前尚未经过实机测试**（属于实验性扩展支持），向导默认不会自动启用它们——如需使用，请先在 **【⚙️ 系统设置】** 中手动勾选对应平台、配置并测试凭证确认后再启用。

## 🐍 运行环境：自带便携 Python，无需安装（v1.5.3.3 新增）

本程序**不再要求目标机器预装 Python**。

- 全新机器 / 没有 Python → 双击 **`获取Python.bat`**（约 11 MB，装到程序目录 `.venv\`，不动系统环境、不需要管理员权限）。
- 完全断网 → 包里已带 `vendor\python\python-3.x.y-embed-amd64.zip`，`获取Python.bat --offline` 全程零网络。
- 只有 Python 3.14 / 32 位 / 嵌入版 → 同样走这条路，程序不会降级成"残缺控制台"。
- 要分发给别人 → 在一台能上网的机器上执行：

  ```
  python tools\python_bootstrap.py --fetch --pack
  ```

  把 `dist\python-runtime-*.zip` 一起发出去，对方解压合并后即可断网运行。

命令行细粒度控制（实施员用）：

| 命令 | 作用 |
|---|---|
| `python tools\python_bootstrap.py --plan` | 体检：支持哪些版本、本地有没有离线资产、当前运行时状态 |
| `--auto` / `--auto --offline` | 获取并装配（断网模式只认随包 zip） |
| `--fetch` / `--finalize` | 只取包 / 只装配（分开做便于分发与排错） |
| `--pack` | 打成可分发的运行时压缩包 |
| `--verify` | 校验当前运行时是否真的能解 SQLCipher |
| `--version 3.13.9` / `--base-url http://内网/python` / `--sha256 …` | 指定版本 / 内网源 / 强制校验摘要 |

## 🚀 极简快速启动（任选一种）

### 方式 1：准备环境并启动桌面客户端（最推荐）
1. **（可选）准备环境配置文件**：首次启动时向导会自动生成 `.env`；也可以先复制模板：
   ```bash
   copy .env.example .env
   ```
2. **准备便携 Python（若本机未安装 Python 3.10~3.13）**：双击 **`获取Python.bat`**（支持离线使用随包 `vendor\python\`）；
3. **创建桌面快捷方式并启动**：双击 **`安装桌面App.bat`**（或在终端执行 `python app.py --install`），随后可直接双击桌面 **【待办总结助手】** 图标，或运行 **`启动桌面App.bat`** / **`Start.bat`**；
4. **首次引导与确认配置（必做）**：打开界面后请按 **新手向导** 指引操作，**务必进入【⚙️ 系统设置】页面确认配置模式、勾选需要启用的平台并完成凭证校验后点击「保存配置并应用」**，确认配置之后系统才会正式生效运行。

### 方式 2：Python 命令行一键启动
如果您习惯在终端运行 Python，直接在项目根目录下执行：
```bash
python app.py
```
*(系统将自动检查后台服务，并以独立的桌面 App 窗口呈现应用界面)*

### 方式 3：直接启动服务
运行 `python server.py`，系统将在后台启动控制台服务并自动以独立应用模式唤起桌面窗口。

## 🛡️ 三大工程原则承诺

1. **绝对安全只读**：仅在本地复制聊天数据库副本再解密，绝不向原库写入任何字节，绝不打扰正常聊天，绝不向外泄露原始聊天记录。
2. **真实信源可溯**：清单每条待办必须具备【会话名、发送人、发送时间、消息编号】，无法溯源的内容绝不进入待办清单。
3. **故障主动告警**：读取失败时主动生成《异常诊断单》并在清单首行报警，安全冻结增量游标，修复后原位补录，绝不漏消息。

## 🗑️ 一键完全卸载与痕迹彻底清理

针对“软件删不干净、开机后台常驻、残留快捷方式与解密缓存”的痛点，本系统内置了 **100% 深度彻底卸载机制**，任选一种方式即可将系统完全恢复如初：

### 方式 1：双击批处理一键彻底卸载（推荐）
在软件根目录下直接**双击运行 `彻底卸载.bat`**（或 `Uninstall.bat`）：
1. 自动停止后台常驻采集调度进程；
2. 自动注销 Windows 开机自启动项 (`ChatTodoWatcher` / `ChatTodoScheduler`)；
3. 自动删除桌面上的【待办总结助手】快捷方式及开始菜单图标；
4. 彻底还原 QQ 自动更新组件（清除所有免疫占位目录与改名备份）；
5. 彻底销毁本地明文解密镜像 (`work/wx_mirror`)、浏览器 App 缓存 (`work/.app_profile`) 与密钥环；
6. 清理完成后，您只需直接将本软件文件夹删除移入回收站即可，系统零残留！

### 方式 2：在 App 界面中一键清理
进入控制台【⚙️ 系统设置】页面，拉到底部“软件彻底卸载与痕迹完全清理”卡片，点击 **【🗑️ 一键彻底卸载并清理全部数据】** 按钮，系统将执行相同深度清理并安全关闭服务。
