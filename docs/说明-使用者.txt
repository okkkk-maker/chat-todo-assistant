待办汇总助手 v1.4.1（构建 2026-11-06，stable）
------------------------------------------------------------

待办汇总助手 · 程序包 B（使用者用）
====================================

给校长/院长：您只需要记住两件事。

一、平时怎么用
    安装好之后什么都不用做：
      · 程序每 3 小时自动采集一次（登录后常驻，计划见 config\schedule.json）；
      · WorkBuddy 每 3 小时自动提炼并推送一份清单到企业微信。
    想立刻整理一次：双击 Start.bat 打开控制台 → 点【⚡ 立即采集】，
    或在命令行执行 Start.bat --no-open --hours 4。

    不需要输入任何内容，不需要登录任何账号。

二、采集时窗口里四条提示的意思
    [1/4] 正在检查 QQ 与企业微信运行状态...
    [2/4] 正在安全读取本地增量消息（只读模式，不影响聊天）...
    [3/4] 已提取 X 条有效消息素材，正在唤醒 WorkBuddy 智能提炼...
    [4/4] 正在触发 WorkBuddy 汇总推送...

    看到 🟢 就是正常；🟡 是提醒您电脑上的 QQ 退出了，双击登录一下就好；
    🔴 是读取异常，请把 output 文件夹里的「异常说明」发给维护人员。

三、三条承诺
    · 只读：程序只复制聊天记录副本再读取，您的聊天不受影响，也不会对外发送。
    · 不编造：清单里每一条都带来源（会话、发送人、时间、消息编号），
      找不回来源的内容不会出现在清单里。
    · 不隐瞒：读不到数据时会明确报警，绝不会给您一份“看起来没事”的空清单。

四、常见情况
    · 电脑 QQ 退出了 → 手机上的新消息不会同步到电脑，双击登录 QQ 即可。
    · 换了 QQ 号登录 → 需要维护人员重新运行一次初始化（A 包）。
    · 想立刻整理一次 → 双击 Start.bat 就行，不用等定时任务。
    · 窗口提示“另一个待办汇总实例正在运行中，本轮自动跳过”
      → 说明上一轮还没跑完（比如开机自启刚跑起来），这是防止两个程序互相
        抢文件造成误报的保护机制，不是故障，等下一轮即可。

技术信息（给维护人员）
    · 数据来源：QQ 本地消息库（只读解密）+ 个人微信本地库（SQLCipher4，只读）
      + 飞书 OpenAPI + 企微/钉钉收件箱
    · 素材：work\待办素材.json    清单：output\todo-*.md
    · 后台日志：output\background.log、output\scheduler.log
    · 定时采集：登录后自动运行，每 3 小时一次（计划见 config\schedule.json）
        查看：python tools\scheduler.py status
        立即：python tools\scheduler.py run-now
    · 微信体检：python tools\wxkey.py status
    · 微信密钥：控制台点「🔑 自动抓取微信密钥」（4.0/4.1 通用，2~3 秒，不用重启微信）；
      或双击 WeChat_Key.bat 选 1。抓取任务在后台跑，超时提示不等于失败，别反复点
    · 手动跑一次：python run.py --no-open
