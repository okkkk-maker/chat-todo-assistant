待办汇总助手 v1.0.1（构建 2026-10-29，stable）
------------------------------------------------------------

待办汇总助手 · 程序包 A（实施员用）
====================================

适用对象：实施员 / 维护人员。终端用户（校长、院长）不需要看这份说明。

一、这个包做什么
    在目标电脑上跑一次 Admin_Init.bat，自动完成：
      1. 找到正确的主 QQ 号与消息库
      2. 引导取出数据库密钥（唯一要人工配合的一步：在弹出的 QQ 窗口点一次“登录”）
      3. 探测加密参数、固化真实表结构到 config\schema.json
      4. 锁死 QQ 自动更新，保住密钥与表结构
      5. 确认推送通道（默认用 WorkBuddy 内置企微连接器，无需地址）并注册开机自启

二、怎么用
    0. 运行环境所需依赖已随包提供（vendor\wheels），断网也能装好，无需 pip 联网。
    1. 把「1-实施员一键初始化包」和「2-用户日常全自动运行包」
       都解压到同一个文件夹（A 先解压，B 再覆盖进来），
       也可以直接用 qq-todo-绿色版 这一个目录。
    2. 右键 Admin_Init.bat → 以管理员身份运行（脚本自己也会申请提权）。
    3. 看到“【人工配合 30 秒】”提示后，在弹出的 QQ 登录框点“登录”或扫码。
       （向导会先花约 1 分钟分析 wrapper.node，再自动关掉并重启 QQ 挂调试器，别以为卡住了）
    4. 推送不需要填任何地址：摘要由 WorkBuddy 定时任务调用内置企微连接器发送；
       群机器人 Webhook 只是可选兜底，引导里默认跳过。
    5. 全部打勾（✔）即完成；出现 ✘ 就按提示补，可重复运行，已完成的步骤会自动跳过。

三、耗时与注意事项
    · 全程约 3 分钟，其中人工只需要点一次登录。
    · 取密钥时 QQ 会被自动关闭并重启一次，属于正常现象。
    · 需要管理员权限（附加调试器、改程序目录都要）。
    · 完成前不要交付给使用者。看到“程序包 A 完成”才算跑通。

四、跑完之后
    · 先用 Start.bat 试跑一次，确认素材生成正常（work\待办素材.json）。
    · 采集已自动化：初始化会把「常驻采集调度」注册进启动项，登录后按
      config\schedule.json 的计划自动采集（默认每 180 分钟 / 3 小时，回看 4 小时）。
        查看状态: python tools\scheduler.py status
        改间隔  : python tools\scheduler.py --interval 180
        改时刻  : python tools\scheduler.py --daily 08:30,17:30
        立即跑  : python tools\scheduler.py run-now
    · 在 WorkBuddy 里建定时任务（只负责提炼+推送，采集已由调度器完成）：
      提示词优先用包里的 automation-prompt.local.md
      （初始化时自动生成，已把 output/ work/ 换成本机真实绝对路径）；
      automation-prompt.md 是可移植模板，不含任何写死的盘符。
      周期：**每 3 小时一次**（与程序侧调度一致；WorkBuddy 侧 rrule 用 FREQ=HOURLY;INTERVAL=3）。
    · 想恢复 QQ 自动更新：python tools\lock_qq_update.py --restore

五、微信通道（4.x）
    · 前提：本机装了微信 4.x 并且**由使用者本人双击启动并登录**。
      脚本/后台拉起的微信不会读库，也就抓不到密钥。
    · 取密钥：确认微信已登录 → 控制台「微信密钥 → 自动抓取」，或
      python tools\wxkey.py acquire（4.0.x 与 4.1+ 同一套操作，2~3 秒，不用关微信）
      4.1+ 是每库一密钥，程序会一次取全并存到 work\wx_keys.json；
      校验方式是 page1 HMAC，通过才落盘，不会再把正确密钥判错。
    · 抓不到时：先确认微信主进程 >500MB、窗口标题是本人昵称、且是桌面双击启动的；
      4.0 可点开聊天再抓一次；4.1 必须彻底退出微信（托盘也退）后用「重启时抓取」。
    · 体检：python tools\wxkey.py status
    · 不再需要把 vendor\ 拷到用户包，解密内核已内置（tools\wxdecrypt.py）。

六、排错
    · 找不到 QQ 号目录：确认 QQ 装在本机且登录过；或改 .env 里的 QQ_DB_PATH。
      默认会扫 C:\Tencent Files 与 D/E/F 盘同名目录，以及「文档\Tencent Files」。
    · 密钥解不开：QQ 可能升级/换号，重跑本向导（重新取密钥 + 重新探测表结构）。
    · 向导卡在“分析 wrapper.node”：该文件约 120MB，静态分析要 1 分钟左右，属正常。
    · 取密钥超过 3 分钟会强制超时退出（不再无限死等）：多半是登录框没弹出、
      杀软拦了调试器，或 PowerShell 卡死；关掉实时防护后重跑即可。
    · 脚本报“找不到 QQ 安装路径”：QQ 装在非标准目录时，向导会自动定位并显式传路径；
      若仍失败，用 python toolsdmin_init.py --check 看它定位到哪儿。
    · 只想体检不改东西：python tools\admin_init.py --check
